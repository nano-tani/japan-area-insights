# データ出典方針

最終確認日: 2026-09-02

## 国土交通省 不動産情報ライブラリ

公式: https://www.reinfolib.mlit.go.jp/

APIは利用申請・承認後に発行されるAPIキーをHTTPSリクエストの `Ocp-Apim-Subscription-Key` ヘッダーへ設定して利用する。ブラウザから直接呼び出さず、Pythonの取得処理だけで使用する。

MVPで採用するAPI:

- XIT001: 不動産価格（取引価格・成約価格）情報
- XPT002: 地価公示・都道府県地価調査ポイント

XPT002はズーム13～15のタイルAPIなので、MVPでは東京都23区を含む範囲を取得し、`city_code` で23区だけを抽出して市区単位の平均値を作る。地価公示と都道府県地価調査は別項目で保存する。

## e-Stat / 令和7年国勢調査 速報集計

公式: https://www.e-stat.go.jp/

API利用にはアプリケーションIDが必要。MVPでは2026-05-29公開の次の2表を採用する。

- 表1-1 `0004050397`: 男女別人口－全国、都道府県、市区町村
- 表1-2 `0004050417`: 2020年人口（組替）、世帯数、2020年世帯数（組替）、5年間の人口・世帯増減等

2025年人口、2025年世帯数、5年間の人口増減率・世帯増減率と、2025年境域に組み替えた2020年人口・世帯数を保存する。

## 国土数値情報 250mメッシュ別将来推計人口

公式: https://nlftp.mlit.go.jp/ksj/

2024年度版「250mメッシュ別将来推計人口（R6国政局推計）」を採用する。2020年国勢調査を基準に2070年までを推計したデータで、東京都CSV ZIP `250m_mesh_suikei_2024_csv_13.zip` を使用する。

CSVはShift-JIS形式。`SHICODE` で23区を抽出し、`MESH_ID` ごとに `PTN_2020`、`PTN_2025` ～ `PTN_2070` を保存する。公開時は市区単位へ合計し、2025年を100とした人口維持率を表示する。

利用時は国土情報利用約款に従い、出典が国土数値情報であることと加工者を明示する。

## 出典管理

取得データには最低限、次を保存する。

- source_name
- source_url
- dataset_id / api_id
- fetched_at
- published_at（取得できる場合）
- terms_url
- raw_hash（可能な場合）

数値を画面に出す場合、どのデータから作ったかを追跡できる状態にする。

## 禁止事項

公開JavaScriptへAPIキーを埋め込まない。取得規約を確認していない民間施設データを自動収集しない。欠損値をAIや推測値で補完して公開しない。
