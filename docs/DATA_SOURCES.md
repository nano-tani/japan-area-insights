# データ出典方針

最終確認日: 2026-09-02

## 国土交通省 不動産情報ライブラリ

公式: https://www.reinfolib.mlit.go.jp/

APIは利用申請・承認後に発行されるAPIキーをHTTPSリクエストの `Ocp-Apim-Subscription-Key` ヘッダーへ設定して利用する。ブラウザから直接呼び出さず、Pythonの取得処理だけで使用する。

MVPで優先するAPI:

- XIT001: 不動産価格（取引価格・成約価格）情報
- XPT002: 地価公示・地価調査
- XKT006: 学校
- XKT007: 保育園・幼稚園等
- XKT013: 将来推計人口250mメッシュ
- XKT017: 図書館
- XKT018: 市区町村役場及び集会施設等
- 都市計画・防災系APIは第2段階で追加

公式マニュアル上、XIT001の不動産取引価格情報は2005年第3四半期以降、成約価格情報は2021年第1四半期以降。XPT002の地価公示は1995年以降、地価調査は1997年以降が整備範囲。

## 国土数値情報 250mメッシュ別将来推計人口

公式: https://nlftp.mlit.go.jp/ksj/

2024年度版は2020年国勢調査を基準に、2070年までの250mメッシュ別将来人口を推計している。MVPでは23区境界との集約処理を行い、市区単位の将来人口と人口維持率を作る。

## e-Stat

公式: https://www.e-stat.go.jp/

API利用にはアプリケーションIDが必要。人口・世帯・年齢構成の取得元として使用する。2025年国勢調査の人口速報集計は2026-05-29に公開されているが、MVPでどの統計表を正式採用するかは列定義と継続性を確認してから固定する。

## 出典管理

取得データには最低限、次を保存する。

- source_name
- source_url
- dataset_id / api_id
- fetched_at
- published_at（取得できる場合）
- terms_url
- raw_hash（可能な場合）

数値を画面に出す場合、どのデータから作ったかを追跡できる状態にする。

## 禁止事項

公開JavaScriptへAPIキーを埋め込まない。取得規約を確認していない民間施設データを自動収集しない。欠損値をAIや推測値で補完して公開しない。
