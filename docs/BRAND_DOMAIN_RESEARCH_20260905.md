# ブランド・独自ドメイン候補調査（2026-09-05）

## 結論

公開名は現時点で変更しない。第一候補を **「住み座標」**、ドメイン表記候補を **`sumizahyo.jp`** として最終確認へ進める。

「街スコア」は同じ読みの既存サービス「まちスコア（machiscore.jp）」と事業領域が近く、長期ブランドとしては識別性が弱い。独自ドメイン取得前に切り替える方針を維持する。

ただし、検索エンジンで同名サービスが見つからないことと、商標登録可能であること、ドメインを取得できることは別問題である。**J-PlatPatでの称呼類似検索と、取得直前のJPRS WHOIS / レジストラ検索が完了するまでは公開ブランドを変更しない。**

## 第一候補「住み座標」のブランド定義

### 約束

> 今だけでなく、これからも住む場所を、公的データで見比べる。

### サービスの説明

- 駅中心1km圏を共通単位として比較する
- 250mメッシュで「駅のどこ側を見るか」まで掘る
- 2025〜2045年の将来人口を主役にする
- 価格、防災、生活、交通を独立した判断材料として見せる
- 総合点は参考値に下げ、元データ・出典・信頼度を見せる
- 広告報酬をスコア・ランキングの入力にしない

### 表記案

- 日本語ロゴ: `住み座標`
- 英字補助表記: `SUMI ZAHYO`
- 第一ドメイン候補: `sumizahyo.jp`
- 防御取得候補: `sumizahyo.com`（費用と空き状況次第）

日本語ドメインは主URLには使わない。SNS・口頭共有・メール・解析・外部サービス連携でASCIIドメインの方が扱いやすいため。

## 事前検索の状態

2026-09-05時点の一般Web検索では、「住み座標」「SUMIZAHYO」を名称とする確立した住み替え・不動産・街比較サービスは確認できなかった。一方、「住み先」は一般文中で使われる語であり、「住み軸」は名称として短いものの意味が広い。

これは**商標クリアランスではない**。正式決定前に以下を実施する。

## 商標の最終確認手順

J-PlatPatの商標検索で、最低でも次を確認する。

1. `商標(検索用)` で「住み座標」
2. `称呼(単純文字列検索)` で「スミザヒョウ」
3. `称呼(類似検索)` で「スミザヒョウ」
4. 表記揺れ・英字（SUMIZAHYO / SUMI ZAHYO）
5. 想定役務と近い区分・類似群を確認する

本サービスで特に確認対象になり得る国際分類の例は、36類（不動産関連情報等）、42類（ソフトウェア/SaaS等）、35類（広告・事業情報等）。実際の指定役務・類否判断は出願時に専門家またはJ-PlatPatの最新分類で再確認する。

J-PlatPatの類似検索結果に表示された商標が直ちに法的に類似という意味ではなく、逆に検索漏れがないことも保証されないため、公開名確定時は最終確認を別工程として扱う。

## ドメインの最終確認手順

1. JPRS WHOISで `sumizahyo.jp` の登録状況を確認
2. 実際に購入するレジストラで取得可否と更新料金を確認
3. 取得可能なら `.jp` を先に確保
4. 必要なら `.com` も防御取得
5. GitHub Pagesのcustom domainを設定
6. `JAI_SITE_NAME=住み座標` と `JAI_SITE_URL=https://<取得ドメイン>` で公開ページを再生成
7. canonical / sitemap / robots / HTTPSを検証
8. Search Consoleに新ドメインを登録

WHOISにレコードがない場合でも予約・登録処理中等の可能性があるため、最終的な取得可否はレジストラの購入画面で確定する。
