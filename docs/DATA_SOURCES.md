# データ出典方針

最終確認日: 2026-09-04

## 国土交通省 不動産情報ライブラリ

公式: https://www.reinfolib.mlit.go.jp/

APIは利用申請・承認後に発行されるAPIキーをHTTPSリクエストの `Ocp-Apim-Subscription-Key` ヘッダーへ設定して利用する。ブラウザから直接呼び出さず、Pythonの取得処理だけで使用する。

MVPで採用するAPI:

- XIT001: 不動産価格（取引価格・成約価格）情報
- XPT002: 地価公示・都道府県地価調査ポイント
- XKT006: 学校（令和5年度）
- XKT007: 保育園・幼稚園等（令和5年度）
- XKT010: 医療機関（令和2年度）
- XKT013: 国土数値情報（将来推計人口250mメッシュ）
- XKT015: 駅別乗降客数（令和5年度）
- XKT017: 図書館（文化施設・平成25年度）
- XKT018: 市区町村役場及び集会施設等（令和4年度）

XPT002はタイルAPIなので、MVPでは東京都23区を含む範囲を取得し、`city_code` で23区だけを抽出して市区単位の平均値を作る。地価公示と都道府県地価調査は別項目で保存する。

XKT013は国土数値情報「250mメッシュ別将来推計人口（R6国政局推計）」を返す。`MESH_ID` と `SHICODE` を使って23区を抽出し、`PTN_2020` ～ `PTN_2070` を保存する。公開時は市区単位へ集約し、2025年を100とした人口維持率を表示する。

### 生活利便性

生活利便性は XKT006 / XKT007 / XKT010 / XKT017 / XKT018 を使用する。

カテゴリは次の5つとする。

- 学校
- 保育園・幼稚園等
- 医療機関
- 図書館
- 公共施設

各カテゴリについて人口1万人あたり施設数を計算し、東京23区内のパーセンタイル順位を求める。5カテゴリの順位を均等に平均し、その合成値を再度相対評価して15点満点へ変換する。

XKT006のうち幼稚園・こども園はXKT007と重複しやすいため学校カテゴリから除外する。XKT017は国土数値情報の文化施設データを基礎とし、大学図書館等を含む可能性がある。掲載されていることだけを根拠に一般利用可能とは表示しない。

XKT010は行政コードが直接取得できないため、施設座標を約250mの4分の1地域メッシュコードへ変換し、XKT013の `MESH_ID` と `SHICODE` の対応で区を割り当てる。住所に区名がある場合は補助的に使用する。

### 交通利便性

XKT015の駅別乗降客数データを使用する。令和5年度データでは駅名、駅コード、駅グループコード、事業者名、路線名、2023年の乗降客数などを利用する。

駅座標から約250mの4分の1地域メッシュコードを求め、XKT013の `MESH_ID` → `SHICODE` 対応で区を割り当てる。行政界上・行政界付近の駅では厳密な境界ポリゴン判定と異なる可能性があるため、将来は行政区域ポリゴンによる点-in-polygon判定へ置き換える余地がある。

交通利便性15点は次の3指標を均等に合成する。

- 人口10万人あたり駅数（駅グループ単位）
- 区内のユニーク路線数
- 駅別乗降客数合計 ÷ 人口

同一駅グループに複数レコードがある場合、乗降客数はグループ内の最大値を使い、同じ駅の重複加算を抑える。

## e-Stat / 令和7年国勢調査 速報集計

公式: https://www.e-stat.go.jp/

API利用にはアプリケーションIDが必要。MVPでは2026-05-29公開の次の2表を採用する。

- 表1-1 `0004050397`: 男女別人口－全国、都道府県、市区町村
- 表1-2 `0004050417`: 2020年人口（組替）、世帯数、2020年世帯数（組替）、5年間の人口・世帯増減等

2025年人口、2025年世帯数、5年間の人口増減率・世帯増減率と、2025年境域に組み替えた2020年人口・世帯数を保存する。

## 国土数値情報 250mメッシュ別将来推計人口

原典: https://nlftp.mlit.go.jp/ksj/

2024年度版「250mメッシュ別将来推計人口（R6国政局推計）」は2020年国勢調査を基準に2070年までを推計したデータ。通常運用では不動産情報ライブラリ XKT013 経由で取得する。東京都CSV ZIP `250m_mesh_suikei_2024_csv_13.zip` の直接取込は予備経路として残す。

## スコア v0.3

総合100点は次の6項目で構成する。

- 価格動向 20
- 人口動向 20
- 将来人口 20
- 生活利便性 15
- 交通利便性 15
- 取引活性度 10

全項目とも東京23区内の相対評価とする。必要な項目が欠損している場合、欠損を0点に置き換えず総合点は未算出とする。取引活性度は年途中の件数による歪みを避けるため、原則として直近の完了年の取引件数を使用する。

災害リスクは総合点へ含めない。

## 出典管理

取得データには最低限、次を保存する。

- source_name
- source_url
- dataset_id / api_id
- fetched_at
- published_at（取得できる場合）
- terms_url
- raw_hash（可能な場合）

数値を画面に出す場合、どのデータから作ったかを追跡できる状態にする。

## 禁止事項

公開JavaScriptへAPIキーを埋め込まない。取得規約を確認していない民間施設データを自動収集しない。欠損値をAIや推測値で補完して公開しない。
