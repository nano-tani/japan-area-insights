# MVP仕様

## 目的

東京都23区について、複数の公的データを同じ形式にそろえ、地域の特徴を比較できる状態を作る。

## v0.1で固定する範囲

対象は東京都23区、市区町村単位。公開サイトの主要機能はAIなしで動作する。

公開側は静的サイトとし、SQLiteをブラウザから直接読ませない。Python側でSQLiteからJSONを生成し、`web/data/` に配置する。

## 必須画面

トップページでは23区一覧、検索、ランキング、2地域比較を提供する。

エリア表示では総合点、構成点、地価推移、人口推移、将来人口、出典、災害情報を表示する。データが存在しない項目は推測値で埋めず「データ未生成」とする。

## スコア

総合100点。

| 指標 | 上限 |
|---|---:|
| 価格動向 | 20 |
| 人口動向 | 20 |
| 将来人口 | 20 |
| 生活利便性 | 15 |
| 交通利便性 | 15 |
| 取引活性度 | 10 |

災害リスクは総合点に含めない。

各指標は対象地域内の相対順位を使う。初期の順位帯は次の通り。

| パーセンタイル | 上限に対する得点率 |
|---|---:|
| 上位10% | 100% |
| 上位10〜25% | 85% |
| 上位25〜50% | 65% |
| 下位25〜50% | 40% |
| 下位25% | 15% |

同値は平均順位として扱う。同じ入力に対し同じ得点になることをテストで保証する。

## 信頼度

スコアと別にA〜Dを表示する。v0.1では、データ充足率と直近の取引件数から機械的に決定する。

- A: 充足率95%以上かつ取引100件以上
- B: 充足率80%以上かつ取引30件以上
- C: 充足率60%以上かつ取引5件以上
- D: それ未満

この閾値は暫定であり、`score_version` とともに変更履歴を残す。

## 完成条件

23区すべてを識別できること。数値は自動生成されること。出典を追跡できること。同じ入力なら同じスコアになること。ランキングと2地域比較ができること。AIを停止しても主要機能が動作すること。

## 後回し

駅単位、町丁目単位、250mメッシュ表示、地図、民間店舗、独自価格モデル、変化検知、広告・アフィリエイトはMVP完成後に扱う。
